## 1. 오늘 바꾼 방향 (왜 바꿨나)

차가 말하는 장면이 너무 많으면(상황별 질문 9개, 같은 여행 다시 틀기, 끝맺음 멘트…) **가족 목소리가 묻히고 시연 영상도 복잡해진다.**
그래서 앱의 핵심 두 장면만 남겼다.

1. 여행 중 쉬었다 출발할 때 → 가족이 **한마디 남긴다**
2. 나중에 그곳을 다시 지나가면 → **그때 목소리가 나온다** (타임캡슐)

"누구랑 왔고 뭐 먹었는지"는 차가 설명하지 않고 **가족 목소리 안에 담기게** 질문을 바꿨다.
(운전 중엔 앱 화면이 안 보이니까 화면 카드로 설명하는 건 의미 없음. TTS도 아직 막혀 있어서 이름·음식을 차 목소리로 못 읽음)

친구가 만든 기능은 **지우지 않고 스위치로 꺼 둠** → 나중에 켜면 11/6 동작 그대로.

## 2. 목소리 — 지금 동작 전체

### 스위치 (`VoiceRules.kt` 맨 아래)

| 스위치 | 값 | 뜻 |
|---|---|---|
| `SITUATION_QUESTIONS` | `false` | 상황별 질문(비·밤·오래 운전·3명 이상·첫 정차·제일 좋았던 것·다음에 또) 끔 → 질문 2개만 |
| `REPLAY_SAME_TRIP` | `false` | 같은 여행에서 남긴 목소리는 1km 갔다 와도 안 틀어줌 → **예전 여행 목소리만** |
| `CLOSING_PROMPTS` | `false` | "들렀다 갈까요?", "잘 안 들렸어요"를 소리로 안 냄 (화면 글자만) |

기존 값: `DEMO = true` (정차 5초·오래 운전 2분), 반경 300m 등 그대로.

### 여행 한 번 동안 차가 말하는 순서

**① 여행 시작**
- 내비 목적지 or "여행 시작" 버튼 → 탈 사람 고르기 → `v_trip_on` "좋아요. 이번 여행은 제가 차곡차곡 기록해 둘게요."
- 내비 없이 출발 + 집에서 30km 넘게 와서 처음 P → `v_ask_trip` "여행 중이신 것 같아요…" → 예: `v_trip_on` / 아니요: 집 올 때까지 안 물음

**② 쉬었다 출발 (P → D, 중간에 R·N 거쳐도 됨) — 녹음** · `onGearChanged()` → `noAskReason()` → `startMemoryFlow()`
- 조건 전부: 여행 중 / `MIN_STOP_MS`(시연 5초·실제 10분) 넘게 정차 / 집 300m 밖 / 이번 여행에 녹음한 곳 300m 밖
- 음악 멈춤(`focus.pause()`) → 질문 → 삐 → 자동 녹음(말 끝나면 멈춤)
- 질문 (`pickQuestion()`, 스위치 꺼진 상태)
  - 처음 온 곳: `v_ask_after_stop` **"방금 들른 곳, 누구랑 뭐 했는지 한마디 남겨 주세요. 삐 소리가 나면 말해 주세요."** (문장 새로 바꿈)
  - 예전 여행에서 왔던 곳(300m): `v_q_revisit` "예전에도 여기 왔었죠. 그때랑 오늘, 뭐가 달라졌어요?" (이번 여행에서 한 번만)
- 결과: 잘 됨 → `v_saved` / 최고 음량 < `MIN_PEAK` → 소리 없이 화면에 "잘 안 들렸어요" 2.5초, 저장 안 함(다음 정차 때 다시 물음)
- 저장 좌표 = **P 넣은 자리** (`parkedAt`)

**③ 달리다 예전 장소 지남 — 다시 듣기** · `onLocation()`
- 예전 여행(이번 여행 시작 전) 목소리 300m 안 → 음악 줄임(`focus.duck()`) → `v_revisit_intro` "예전에 여기 오셨을 때, 이런 말을 남기셨어요." → 그때 목소리 → 끝
- 한 여행에 한 목소리 한 번 / 여러 개면 가장 최근 것 / 질문·녹음 중이면 안 틈 / 40초 안전 타이머

**④ 집 도착** (여행 중 + 집을 한 번 떠났다가 돌아옴) · `endTripIfHome()`
- `v_welcome_home` "잘 다녀오셨어요…" + 여행 카드 저장(`finishRealTrip()`) + 사진 QR 카드

**⑤ + 버튼으로 직접 남기기** — 질문 없이 삐 → 녹음만 (`recordSpotVoice()`)

**지금 안 나오는 소리:** `v_q_rain/long_drive/night/family/first/best/next`, `v_same_trip_intro`, `v_revisit_stop`, `v_not_heard`, `v_capsule_*`, `v_same_place`, `v_rain` (파일은 있음, 코드에서 안 부름)

## 4. 여행 중 실시간 경로 (지도)

**의도:** 운전 중엔 앱이 안 보이다가, 대전에서 쉬며 앱을 열면 서울역(집)→대전 길이 **점선**으로 보임. 대전→대구로 가면 서울역→대전은 **실선**, 대전→대구는 **다른 색 점선**.

### 구조
- `MainActivity.refreshLive()` → `liveTrip`(점 + 쉬었다 간 곳) / `liveTripOn`(실제 여행 중) / `anyTripOn`(예시 여행 포함)
  - 점: `routes.pointsSince(policy.tripStartedAt)` (시각 기준이라 오늘 앞서 다닌 길은 안 섞임)
  - 쉬었다 간 곳: `policy.tripStops()`
  - 부르는 곳: `refreshPolicyText()` 안, 위치 점 추가될 때(`onLocation`), P 넣을 때, 짧은 정차 지울 때
- **쉬었다 간 곳 기준:** P 넣을 때 `recordTripStop()`으로 일단 남기고, 출발할 때 `MIN_STOP_MS`보다 짧게 섰으면 `policy.dropStopsSince(parkedSince)`로 지움 (`TripPolicy.kt` 새 함수) → 신호대기 같은 짧은 P는 색 구간·여행 카드에 안 나옴
- `onResume()` 새로 추가: 여행 중에 앱을 다시 열면 `mapFitKey++` → `HomeScreen`이 **전체 탭으로 돌아가고** 지도를 이번 여행 길에 맞춤
- `HomeScreen.kt`
  - `data class LiveTrip(points, stops)` / `splitAtStops()` (들른 곳마다 자르기: 순서대로, 500m 안 가장 가까운 점)
  - `updateTracks(..., live)`: 구간마다 `LEG_COLORS` 색, **마지막 구간만 `dash = true`**
    - 막 도착해서 새 구간이 300m도 안 되면 → 방금 도착한 구간(서울역→대전)을 점선으로
  - 레이어: `track-recent-line`(실선, `dash == false`) + **`track-live-line`(점선, `dash == true`, `lineDasharray(0.01, 2.2)` + 둥근 끝 = 동글동글 점)**
  - 여행 중이면 이번 여행 길만 그림. 출발 전이라 점이 없어도 오늘 앞서 다닌 길·지난 날 흐린 길 **안 그림** (11/7 밤에 고친 버그)
- **여행 중 전체 탭:** 지난 여행 사진 핀 + 목소리 핀 숨김 → 집 + 이번 여행 길만. 다른 탭은 평소대로
- **여행이 끝나거나 취소되면:** 전체 탭에서 지나온 길 내림 (`routes = if (anyTripOn) dayRoutes else empty`). 끝낸 여행은 여행 탭 카드에 남음

## 8. 남은 일 · 알려진 문제

1. **⚠️ 앱이 뒤에 있으면 위치를 거의 못 받음 (제일 중요)**
   - 안드로이드는 화면 뒤 앱의 위치 업데이트를 몇 분에 한 번으로 제한 → 3km 넘게 뛴 구간은 일부러 안 이어서 **선이 끊김** (11/7 스샷에서 끊긴 것도 이것으로 추정, 확인 필요)
   - 실제 차에선 운전 내내 내비가 앞에 있으니 **이대로면 여행 경로가 거의 안 남음**
   - 해결안: 여행 기록 중에만 **포그라운드 서비스(type=location)** + "차곡차곡이 여행을 기록 중이에요" 알림. 매니페스트에 `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` 권한 + `<service android:foregroundServiceType="location">`. 위치 요청은 지금처럼 액티비티에서 해도 서비스가 떠 있으면 제한 안 걸림
   - **주최 측에 써도 되는지 아직 안 물어봄** → 물어보고 넣기로 함
2. **점선 모양 확인** — `lineDasharray(0.01, 2.2)` + 둥근 끝으로 점을 만드는 방식. 지도 라이브러리가 너무 짧은 대시를 못 그리면 선이 안 보일 수 있음 → 그러면 `arrayOf(1.2f, 1.2f)` + `LINE_CAP_BUTT` 같은 일반 점선으로
3. **예시 여행(대관령) 돌아오는 길 버그** — `checkPastSpot()`이 `v_revisit_intro` "이런 말을 남기셨어요."만 틀고 **뒤에 목소리가 없음** (사진 카드만 보여주는 옛 방식). 멘트 빼고 카드만 띄우게 고치면 됨 (대양이 OK하면)
4. **데모 목소리 `res/raw/demo_2025_gimcheon.m4a` 녹음** — 10초쯤, 실명 금지(호칭만). 예: 👦 "할머니! 호두과자 하나 더 먹어도 돼?" 👵 "그래그래, 다 같이 오니까 좋다~". 진짜 사람 목소리 추천 (AI 목소리는 성인 목소리뿐이라 아이 느낌 안 남). 파일 넣으면 `seedDemoMemory()`가 김천휴게소(2025-10-04 10:40)에 자동으로 심음
5. **김천휴게소 카드(`e1`)와 데모 목소리 연결 안 됨** — `Spot.voice` 비어 있어서 장소 상세에 "목소리 듣기" 버튼 안 뜸. 필요하면 `seedDemoMemory()`에서 연결
6. `AudioFocus` `USAGE_ASSISTANT` vs `USAGE_MEDIA` — 에뮬레이터에서 안내 소리가 작거나 안 나면 바꾸기

8. **커밋 메시지 정리** — `머리깨질것같노`, `Fuck no.6` 같은 건 GitHub 공개 전에 정리 (11/11에 새 익명 저장소 + 새 히스토리로 올릴 예정이라 그때 깔끔하게)
