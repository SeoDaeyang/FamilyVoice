## 11/7 단순화 — 핵심만 남김

차가 말하는 장면이 너무 많으면 가족 목소리가 묻혀서, 시연과 취지에 맞게 줄였다.
아래 기능은 **지우지 않고 `VoiceRules.kt` 스위치로 꺼 둠** (켜면 11/6 동작 그대로).

| 스위치 | 지금 | 꺼서 바뀐 것 |
|---|---|---|
| `SITUATION_QUESTIONS = false` | 질문 2개만 | 처음 온 곳: "방금 들른 곳, 누구랑 뭐 했는지 한마디 남겨 주세요" · 예전 여행에서 왔던 곳: "그때랑 오늘, 뭐가 달라졌어요?" |
| `REPLAY_SAME_TRIP = false` | 예전 여행 목소리만 재생 | 같은 여행 안에서 1km 갔다가 돌아와도 안 틀어줌 (오늘 남긴 건 다음 여행 때 꺼내짐) |
| `CLOSING_PROMPTS = false` | 끝맺음 멘트 소리 안 냄 | "들렀다 갈까요?", "잘 안 들렸어요"는 화면 글자만 |

- 달리는 중엔 앱 화면을 못 보니까 재생은 **"예전에 여기 오셨을 때, 이런 말을 남기셨어요." → 가족 목소리** 로 끝.
- "누구랑 왔는지"는 여행 카드에 저장 (`Trip.riders`, 출발 전에 고른 사람). 지도에서 핀을 누르면 "함께: …"로 보임.
- 김천휴게소(`e1`) 메모를 "호두과자 한 봉지씩…"으로 바꿈 → 데모 목소리 내용과 맞추기.
- `make_voices.sh`는 이제 **문장이 바뀐 파일만 알아서 다시 만든다** (`scripts/.voice_stamps`). 예전처럼 m4a를 지우고 돌릴 필요 없음.

## 아직 안 된 것

1. **새 안내 음성 4개** — 맥에서 `bash scripts/make_voices.sh` 실행하면 `v_same_trip_intro`, `v_not_heard`, `v_q_best`, `v_q_next`만 새로 생긴다. 새 질문 음성이 없으면 기본 질문 음성으로 대신 나감. 없으면 안내 없이 카드만 뜬다. (기존 `v_same_place`는 "해마다 이어서 들려드릴게요"라 문장이 안 맞아서 안 씀)
2. **작년 목소리 녹음 파일** — `demo_2025_gimcheon.m4a` (10초, 실명 말고 "엄마, 할머니" 같은 호칭). 없으면 아무 일도 안 일어난다.
3. **빌드·실행 확인 전** — 코드만 고쳤다. 아래 체크리스트로 확인 필요.
4. **오디오 포커스 실제 효과 미확인** — 에뮬레이터에서 안내 소리가 너무 작거나 안 나면 `AudioFocus.kt`의 `USAGE_ASSISTANT` → `USAGE_MEDIA`.
5. **네비 안내와의 겹침** — 네비가 우선이 되도록 앱이 직접 조절하지는 않는다. 차(Pleos) 쪽 소리 우선순위에 맡김.
6. **"한 여행에 한 번만"은 앱 메모리에만 저장** — 여행 중에 앱을 껐다 켜면 같은 목소리가 한 번 더 나올 수 있다.
7. **작년 목소리 ↔ 여행 탭 카드 연결 안 됨** — 경주 여행 김천휴게소 카드(`e1`)에는 목소리가 안 붙어 있다 (`Spot.voice` 비어 있음). 필요하면 연결.
8. **실제값(10분, 1시간 30분)은 제안값 그대로** — 실제 주행으로 검증 안 함.

## 11/8 — 시연은 기어 + 시간으로 (위치 기반 X)

에뮬레이터에서는 주행 중 위치를 제때 못 받아서(안드로이드가 뒤에 있는 앱의 GPS를 줄임)
작년 목소리가 안 나오는 문제가 있었다. 시연 영상은 **위치 대신 기어 변화와 정해진 시간**으로 움직인다.

| 단계 | 기어 | 하는 일 |
|---|---|---|
| 1 | D | 집(서울역) 출발 → 김천휴게소로 (`LEG1_MS` 10초) |
|  |  | 그 길 **7초쯤**(`LAST_YEAR_AT_MS`)에 작년 목소리 (`playLastYearVoice`) |
| 2 | P | 김천휴게소 도착 카드 |
| 3 | D | 출발 → 질문 "그때랑 뭐가 달라졌어요?" → `demo_rec_1` · 황리단길로 (10초) |
| 4 | P | 황리단길 도착 |
| 5 | D | 질문 "다 같이 탔네요" → `demo_rec_2` · 대릉원으로 (5초) |
| 6 | P | 대릉원·첨성대 도착 |
| 7 | D | 질문 "제일 좋았던 거" → `demo_rec_3` · 집으로 (12초) |
| 8 | P | 집 도착 → 여행 기록 + 정리(요약) 화면 → 사진 QR |

- 가상 주행은 `driveAlong(route, durationMs, lastYearAtMs)` — 정해진 시간 안에 경로를 **일정한 속도**로 지나간다.
  차가 말하거나 목소리를 들려주는 중(`flowRunning`)에는 가상 차를 잠깐 세워서 말이 끊기지 않게 한다.
- 경로 좌표는 `TripScenario` (집·김천·황리단길·첨성대). 실제 여행 경로(`Journal.trip("gyeongju").route`)를 잘라서 쓴다.
- **시나리오 중에는 위치 기반 재생을 끈다** (`onLocation` 에서 `scenarioStage != 0` 이면 빠져나감) — 타이밍이 두 번 울리지 않게.
- 예전 목소리 재생은 `playRevisit(target, sameTrip)` 하나로 모았다 (위치 기반 / 시나리오 둘 다 여기로).
- 질문·녹음은 **원래 로직 그대로** (P 에서 5초 넘게 서 있다가 D). 집 근처에서는 묻지 않는다 (집 = 서울역 고정).
- `scripts/drive_trip.sh` 는 이제 시연에 꼭 필요하지 않다 (실제 위치 기반 동작을 확인할 때만).
